- Lab Day 14 (deployment, benchmark, observability), làm từ đầu giờ chiều đến tối: làm lần lượt checkpoint, deploy, đo, viết báo cáo, nộp.

- Đã cài sẵn Docker, WSL2 và xem lướt README trước buổi; đọc kỹ đề vào đầu buổi.
- Kiểm bài theo checklist trong file nộp bài, chạy lại script chấm, thử API, rà file và ảnh minh chứng.

## Trả lời lại (nguyên văn, theo thứ tự 7 câu)

1. "Bài Day 14, mình làm từ đầu giờ chiều đến tối. Làm các checkpoint, deploy lên VPS, chạy benchmark rồi viết báo cáo nộp."
2. "Lâu nhất là phần Docker với deploy, tầm 1–2 tiếng. Có mấy lỗi cấu hình, thiếu file môi trường, trùng tên project rồi cả HTTPS nữa."
3. "Chủ yếu đọc log, xem hướng dẫn với hỏi AI. Nhiều lúc sửa xong vẫn lỗi, phải thử lại. Tài liệu chia nhiều file nên tìm cũng hơi mất công."
4. "Trước buổi mình có cài Docker, WSL2 rồi, cũng xem qua README. Còn đề chi tiết thì vào buổi mới đọc kỹ."
5. "Chạy lại script chấm, thử API rồi kiểm tra file báo cáo, ảnh chụp theo checklist. Khoảng 20–30 phút."
6. "Chưa gặp."
7. "Không nhớ số buổi cụ thể nhưng gần như buổi nào cũng có lỗi phải xử lý hoặc chạy lại. Kiểm tra bài trước khi nộp thì buổi nào mình cũng làm."
